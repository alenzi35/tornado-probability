About

This system visualises tornado probability using gridded atmospheric model outputs. It converts instability, shear, and storm-relative helicity into spatial risk estimates.

Methodology

Inputs include CAPE, CIN, 0–1 km SRH, LCL height, and deep-layer shear. These are combined into a probabilistic field mapped onto a projected grid.

FAQ

This is an experimental system and should not be used for official warning decisions.
